# BSch3V MCP Server

**An MCP server for AI-assisted circuit schematic design and editing.**

This project aims to enable AI tools like Claude to automatically generate and edit schematics for the [BSch3V](http://www.suigyodo.com/online/schsoft.htm) circuit diagram editor via the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/). The goal is for the AI to handle component selection, placement, wiring, and netlist verification in an integrated workflow.

## What It Can Do

### Read & Analyze Schematics
- Load CE3 schematic files and convert to JSON structures
- Generate netlists (NL3W-compatible connection analysis)
- Retrieve component lists, pin coordinates, and net connections

### Create Schematics
- Create new schematics and place components
- Wire routing, junctions, and bus wiring
- Place power symbols, net labels, and tags

### Edit Schematics
- Add, remove, move, rotate, and mirror components
- Add and remove wires
- Modify component properties (name, refdes, display position)
- Change sheet size

### Manage Components
- Search and retrieve components from BSch3V libraries (LB3)
- Copy components from existing schematics (CE3)
- Create new rectangular IC components from pin definitions
- Reuse existing symbols with modified pin numbers/names

## What It Cannot Do

- Produce clean, well-organized schematic layouts. Component placement and wire routing are calculated by the AI using coordinates, but the results will not match the quality of hand-drawn schematics. Schematics generated by the AI are intended to be manually refined in BSch3V.

## Setup

### Requirements
- Node.js v18 or later
- BSch3V (for viewing schematics, [download](http://www.suigyodo.com/online/schsoft.htm))

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/bsch-mcp.git
cd bsch-mcp
npm install
npm run build
```

### Configuration for Claude Code

Create `.mcp.json` in your project:

```json
{
  "mcpServers": {
    "bsch3v": {
      "command": "node",
      "args": ["/path/to/bsch-mcp/dist/index.js"],
      "env": {
        "BSCH3V_DIR": "/path/to/BSch3V"
      }
    }
  }
}
```

`BSCH3V_DIR` should point to the BSch3V installation directory (where `BSCH3.INI` is located). If omitted, common installation paths are searched automatically.

## Usage Examples

### Understand an existing schematic

```
> Read LEDPORT.CE3 and explain the circuit
```

The AI loads the schematic and analyzes component connections and circuit behavior.

### Edit a schematic

```
> Add an LED to the Q4 output of U1
```

The AI adds the necessary components (resistor, LED, GND symbol) and connects them with wires.

### Design and create a new schematic

```
> Design a 4th-order Butterworth low-pass filter with 1kHz cutoff
```

The AI designs the circuit, calculates component values, creates the schematic, and verifies the netlist.

### Create a component from a datasheet

```
> Read the pin layout from the PIC32 datasheet and create a component
```

The AI generates a schematic symbol from pin definitions.

## Supported Formats

| File | Description | Encoding |
|---|---|---|
| `.CE3` | Schematic | UTF-8 / CP932 (auto-detect, writes UTF-8) |
| `.LB3` | Library | UTF-8 / CP932 |
| `BSCH3.INI` | BSch3V config | UTF-16LE |

## Technical Details

- **Language**: TypeScript / Node.js
- **MCP SDK**: `@modelcontextprotocol/sdk`
- **Parser**: Custom CE3/LB3 text format parser and serializer
- **Netlist**: NL3W (BSch3V bundled tool) logic ported to TypeScript
- **Pin coordinates**: Ported from BSch3V C++ source with rotation/mirror support
